# 鷲巣麻雀（開発中）

4人で遊ぶオンライン麻雀を目指す試作です。東風戦・各種4枚のうち3枚が透明な牌・手牌の並べ替え・合言葉での参加を実装中です。**完成版ではありません。**

現状は対局画面と対局サーバー、配牌、打牌、チー・ポン・各種カン、リーチ、ロン、ツモ、点数計算、局進行の基礎処理があります。特殊ルールや途中流局など未対応の部分があり、オンライン対戦全体は未検証です。血液や金銭の要素は設けず、通常の点数で順位を決めます。

このサーバーは試作用で、データはメモリ上にあります。停止・再起動すると部屋と対局情報が消えます。認証とアクセス制御も完成していないため、インターネットへの直接公開はしないでください。

## 開発者向け確認

Node.js 22以降で `node --test tests/*.test.cjs` を実行します。`node src/server.cjs` は `127.0.0.1:3000` で開発用に待ち受けます。サーバーとブラウザの実接続やTailscale経由の動作は未検証です。
