# 鷲巣麻雀

身内向けに開発中の四人打ち東風戦です。合言葉で同じ部屋に入れます。空いている席にはCPUを追加できます。「CPU戦をすぐに始める」で、一人でも配牌から始められます。

## この卓のルール

- 4人個人戦、東1局から東4局、各25,000点持ち。最終順位は持ち点順で、同点は起家に近い席を優先します。
- 34種136枚のうち、各種3枚が透明、1枚が不透明です。相手には透明牌の牌面だけが見えます。手動で理牌すると、その並び順も相手から見えます。
- 卓上には山を積みません。サーバーで牌をシャッフルし、全員が同じ残り牌から重複なく引きます。ドラ表示牌・裏ドラ・嶺上牌のために14枚を取り分けます。親の第一ツモを配った直後の残りは69枚です。
- チーは上家の打牌のみ。ロンを最優先とし、ポン・大明カンはチーに優先します。複数人のロンは頭ハネです。食い替えは禁止です。
- 和了には役が必要です。喰いタンあり、赤ドラなし。一発・裏ドラ・カンドラ・カン裏あり。カンドラはカン成立時に増えます。加カンには槍槓の機会があります。
- 門前テンパイで、持ち点1,000点以上、残り4枚以上ならリーチできます。宣言牌へのロンでは供託しません。リーチ後の打牌はツモ切りで、待ちの変わらない暗カンができます。
- 自分の捨て牌に待ち牌があればフリテンです。鳴かれて河から消えた牌も含みます。役なし側を含む待ち牌の見送りは同巡内フリテン、リーチ後の見送りはその局の終了までフリテンです。フリテン中もツモ和了できます。
- 荒牌流局のノーテン罰符は場に3,000点です。流し満貫、九種九牌、四風連打、四家立直、複数人による四槓散了を採用します。親の和了・流局時の親テンパイ・途中流局は連荘です。親流れで東4局を終えるか、局終了時に持ち点がマイナスになれば終局します。終局時の供託はトップが受け取ります。

## 実行と確認

Node.js 22以降で `node src/server.cjs` を実行し、ブラウザで `http://127.0.0.1:3000` を開きます。テストは `node --test tests/*.test.cjs` で実行できます。部屋と対局情報はサーバーのメモリに保存され、再起動すると消えます。

認証とアクセス制御は試作段階です。不特定多数の利用を想定した運用は未検証です。

点数計算等に [majiang-core](https://github.com/kobalab/majiang-core) を利用しています。ライセンスは `vendor/majiang-core/LICENSE` を参照してください。
